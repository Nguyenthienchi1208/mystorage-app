## Supported parameter extraction (what `app.py` currently parses)
- District: basic matching of common Vietnamese district names and patterns like "quận 2", "q2" → normalized to e.g. `QUẬN 2`.
- Unit Type: keyword detection (`Locker`, `Mini`, `Medium`, `Large`) and a simple volume→unit mapping (e.g., 20m³ → `Medium`).
- Duration / Months: simple regex for patterns like "6 tháng" or "12 tháng"; defaults to 1 month when missing.
- Volume: regex attempts to capture `20m3`, `20 m3`, `20m³` but may be brittle for other formats.
- Customer / Warehouse names: basic SQL ILIKE substring match.

## Coverage notes & known gaps
- Covered: inventory lookups, pricing averages, discount policy, deposit FAQ, expiring contracts, VAS summaries, basic Zalo message generation, occupancy stats.
- Partial / Gaps:
  - Fuzzy district matching (typos, alternate spellings, short names) is limited.
  - Customer and warehouse name matching is simple substring ILIKE (no fuzzy/alias matching).
  - Combined filters (e.g., "Quận 7" AND "máy lạnh") sometimes rely on separate branches; complex multi-intent extraction can be improved.
  - Package suggestion (multi-option proposals based on volume + budget) is only basic — currently maps volume→unit and returns average price.
